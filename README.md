## Projects

### 🔥 Fire Suppression Compliance Checker

A web-based camera application for inspecting and verifying fire suppression systems against state-specific fire safety codes and regulations.

**Features:**
- **Camera Integration**: Uses device camera (WebRTC) to capture images of fire suppression systems
- **Multi-State Support**: Includes compliance rules for CA, NY, TX, FL, IL, PA, OH, GA, NC, MI, and OK
- **System Type Coverage**:
  - Sprinkler Systems
  - Fire Extinguishers
  - Fire Alarms
  - Chemical Suppression Systems
  - Emergency Lighting
  - Exit Signs
- **Building Type Categories**: Commercial, Residential, Industrial, Healthcare, and Educational
- **Automated Compliance Checking**: Analyzes images against state-specific regulations
- **Detailed Reports**: Provides comprehensive compliance status with specific violations and recommendations

**Technology Stack:**
- Pure HTML5, CSS3, and JavaScript (no external dependencies)
- WebRTC for camera access
- Canvas API for image processing
- Responsive design for mobile and desktop

**How to Use:**
1. Select your state from the dropdown
2. Choose the type of fire suppression system you're inspecting
3. Select the building type
4. Grant camera permissions and capture an image
5. Analyze the image to receive a detailed compliance report

**Live Demo:** [Fire Compliance Checker](fire-compliance-checker.html)

**Compliance Standards:**
- NFPA 10 (Fire Extinguishers)
- NFPA 25 (Sprinkler Systems)
- NFPA 72 (Fire Alarm Systems)
- State-specific fire codes and regulations
